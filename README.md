# 帆板控制系统（控制组招新题）· 项目资料

> 纯模拟电路实现：角度误差 → PID 运算 → PWM 调制 → 风扇调速 → 帆板角度稳定。
>
> **⚠️ 本文档为个人整理记录，仅供参考。**
> 其中的器件选型、参数取值、电路结构均为当前方案的工作记录，
> 不代表队伍最终方案，也可能存在理解偏差或计算错误。
> 实际以队内讨论结论和实测数据为准。

## 一、题目要点速查

> 摘自题目原文，仅作速查，以 `00_题目/` 里的原始文件为准。

| 项 | 内容 |
|---|---|
| 硬性 | 纯模拟（禁单片机）、洞洞板、整体结构、0.2m 自由落体后不许调试 |
| 基本要求（70分） | d=15cm，θ 可在 **10~60°** 变化；θ 稳定在 **45°±5°** |
| 发挥部分（30分） | d 在 **10~25cm** 任意，仍稳定 45°±5°，且 **5 秒**内回稳 |
| 供电 | 可外置，调速装置不必含电源 |
| 风扇 | 台式机散热风扇 / 直流轴流；**禁带自动调速功能**（⇒ 必须两线） |

## 四、关键设计参数（速查）

> 下列参数按"帆板固有频率约 1.58 Hz、阻尼比 0.02~0.05"的量级推算，**未经实测验证**。

### 信号链

| 环节 | 参数 |
|---|---|
| 角度标定目标 | **0~5V ↔ 0~60°**（83.3 mV/°） |
| 减法器 | 4×10k 差动，增益 1，e 范围 ±5V |
| 比例增益 | **0~5**（R7 0~50k / R8 10k） |
| 积分时间 Ti | **0~110 ms**（R9 0~50k × C1 2.2µF） |
| 微分时间 Td | **0~110 ms**（R11 0~50k × C2 2.2µF），含 C6 100nF 滚降 |
| 积分泄放 | R10 = 2.2M（限 DC 增益约 44 倍，防饱和） |
| 求和 | 3×10k 输入 / 10k 反馈 / 2.2k 平衡 |

### PWM 调制

| 参数 | 数值 |
|---|---|
| 方波频率 | **约 22.9 kHz**（R20 33k + C3 330pF） |
| 方波幅度 | 0 ~ 3.3V（U4 1N4728A 钳位） |
| 方波基准 | **1.717 V**（R23 13k / R24 6.8k） |
| 三角波幅度 | 0.134 ~ 3.43 V |
| 三角波偏置 | **1.6 V**（R18 47k / R19 100k） |
| 电平匹配比 | **0.32**（R29 10k / R30 4.7k）→ 控制量 0~3.2V |
| 控制量极性 | 控制量↑ → 占空比↑ |

### 功率级

| 参数 | 数值 |
|---|---|
| MOSFET | IRLZ34N（TO-220，Qg 约 17nC，**实物待核实**） |
| 续流二极管 | 1N5819（肖特基，**不可用 1N4007 / 稳压管**） |
| 栅极上拉 | 1k → +12V |
| 栅极串阻 / 下拉 | 100Ω / 100k |
| 预计管耗 | 约 0.3 W（0.4A 风扇），可不加散热片 |

### 抗噪

| 参数 | 数值 |
|---|---|
| 反馈低通 | 470Ω + 10µF → **约 35 Hz**（23kHz 衰减约 56dB） |
| 接地 | 功率地 / 信号地单点汇合于电源端子 |
| 反馈通道增益损耗 | 约 4.5%（由 470Ω 与 10k 分压造成，标定时补偿） |

## 五、待确认事项

1. **「纯模拟」的边界**：NE555 / 比较器 / 门电路 / 稳压模块是否允许 ← 影响较大
2. 发挥部分编号只有 1)、3)，缺 2)，是否漏写
3. 0.2m 自由落体落在什么面、落几次
4. d 的测量基准；变 d 时是移动风扇还是移动帆板
5. 基本要求 2) 的"稳定 45°±5°"是否有时限
6. "不得有额外包裹物"是否允许内部减震
7. 量角器自带还是统一提供
8. 现场允许几路电源、电压上限
