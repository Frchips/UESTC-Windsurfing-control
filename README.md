## 题目要点速查

> 以下摘自题目原文，仅作速查用，以原始 docx 为准。

| 项 | 内容 |
|---|---|
| 硬性 | 纯模拟（禁单片机）、洞洞板、整体结构、0.2m 自由落体后不许调试 |
| 基本要求（70分） | d=15cm，θ 可在 **10~60°** 变化；θ 稳定在 **45°±5°** |
| 发挥部分（30分） | d 在 **10~25cm** 任意，仍稳定 45°±5°，且 **5 秒**内回稳；其它（焊接/机械） |
| 供电 | 可外置，调速装置不必含电源 |
| 风扇 | 台式机散热风扇/直流轴流；禁带自动调速功能 |

## 设计思路备忘（个人整理 · 待队内讨论）

> 下列内容是人家的初步理解和倾向，**都可能被推翻**，写下来只为方便讨论时有话可聊。

| 项 | 初步想法 | 考虑因素 |
|---|---|---|
| 供电 | 看书上多数做法用 **±12V 双电源** | 12V 与风扇电压一致；用双电源的理由是"误差 e 可能需要正负两个方向" |
| 运放 | 倾向 **TL07x 系列（JFET 输入）** | 积分级可能对偏置电流比较敏感（LM324 的 Ib 似乎会让积分电容漂移，具体没细算） |
| PID 拓扑 | 参考**并行型**（P / I / D 三支路 + 求和） | 好处是三路可以分别焊、分别测，调试时心里有数 |
| 减法器 | 倾向单独做一级 | 这样 e 是个能拿万用表量的点，分段验收方便些 |
| 角度传感 | 考虑**轴端磁铁 + 线性霍尔** | 担心电位器的摩擦力矩会造成死区；但也可能实际影响没想象的大，需要实测 |
| 帆板 | 初步按 **10~25 g** 估算 | 轻一点所需风速小；具体多重还得看实测能不能吹上去 |
| 风扇 | 考虑 **120mm、2 线、12V** | 主要是担心 4 线风扇被判"自带调速"；风量够不够要试 |
| 功率级 | **还没定**，线性和 PWM 都在看 | 线性噪声小但要散热；PWM 效率高但干扰不好处理 |

## 待确认事项（建议向负责同学或老师问清）

1. **「纯模拟」的边界**：NE555 / 比较器 / 门电路 / 稳压模块算不算允许 ← 这条影响较大
2. 发挥部分编号只有 1)、3)，缺 2)，是否漏写
3. 0.2m 自由落体落在什么面、落几次
4. d 的测量基准；变 d 时是移动风扇还是移动帆板
5. 基本要求 2) 的"稳定 45°±5°"是否有时限（参考原题的 10 秒）
6. "不得有额外包裹物"是否允许内部减震
7. 量角器自带还是统一提供
8. 现场允许几路电源、电压上限
