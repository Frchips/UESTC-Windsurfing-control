# 帆板控制系统（控制组招新题）· 项目说明

> **题目**：用纯模拟电路（禁止单片机）控制风扇转速，使 10cm×15cm 的帆板稳定在指定角度。
>
> **实现思路**：角度误差 → 减法器求 e → 并行 PID（P/I/D 三支路求和）→ 电平匹配 → PWM 调制 → MOSFET 驱动风扇 → 角度闭环。

> **⚠️ 说明**
>
> 本文档为项目当前状态的整理记录，**仅供队内参考**。
> 电路参数按"帆板固有频率约 1.58 Hz、阻尼比 0.02~0.05"的量级推算，**尚未经实测验证**；
> 机械尺寸为建议打样值，**不是已完成校核的施工图**。
> 最终方案以队内讨论结论和实测数据为准。

## 一、题目要点

> 摘自题目原文，以 `00_题目/` 里的原始文件为准。

| 项 | 内容 |
|---|---|
| 硬性 | 纯模拟（禁单片机）、洞洞板、整体结构、0.2m 自由落体后不许调试或修复 |
| 基本要求（70分） | d=15cm，θ 可在 **10~60°** 变化；θ 稳定在 **45°±5°** |
| 发挥部分（30分） | d 在 **10~25cm** 任意，仍稳定 45°±5°，且 **5 秒**内回稳 |
| 供电 | 可外置，调速装置不必含电源 |
| 风扇 | 台式机散热风扇 / 直流轴流；**禁带自动调速功能**（⇒ 必须选两线风扇） |
| 角度定义 | 相对竖直向下方向，竖直向下为 **0°** |
| **间距 d 定义** | **风扇出风面 → 转轴竖直投影的距离**（不是到倾斜帆板最近处） |
| 量角器 | **必须安装在转轴处** |

## 四、关键设计参数

> 按"帆板固有频率约 1.58 Hz、阻尼比 0.02~0.05"的量级推算，**未经实测验证**。

### 信号链

| 环节 | 参数 |
|---|---|
| 角度标定目标 | **0~5V ↔ 0~60°**（83.3 mV/°） |
| 减法器 | 4×10k 差动，增益 1，e 范围 ±5V |
| 比例增益 | **0~5**（R7 0~50k / R8 10k） |
| 积分时间 Ti | **0~110 ms**（R9 0~50k × C1 2.2µF） |
| 微分时间 Td | **0~110 ms**（R11 0~50k × C2 2.2µF），含 C6 100nF 滚降 |
| 积分泄放 | R10 = 2.2M（限 DC 增益约 44 倍，防积分饱和） |
| 求和 | 3×10k 输入 / 10k 反馈 / 2.2k 平衡 |

### PWM 调制

| 参数 | 数值 |
|---|---|
| 方波频率 | **约 22.9 kHz**（R20 33k + C3 330pF） |
| 方波幅度 | 0 ~ 3.3V（U4 1N4728A 钳位） |
| 方波基准 | **1.717 V**（R23 13k / R24 6.8k） |
| 三角波幅度 | 0.134 ~ 3.43 V |
| 三角波偏置 | **1.6 V**（R18 47k / R19 100k） |
| 电平匹配比 | **0.32**（R29 10k / R30 4.7k）→ 控制量 0~3.2V |
| 控制量极性 | 控制量↑ → 占空比↑ |

### 功率级

| 参数 | 数值 |
|---|---|
| MOSFET | IRLZ34N（TO-220，Qg 约 17nC，**实物待核实**） |
| 续流二极管 | 1N5819 肖特基（**不可用 1N4007，更不可用稳压管**） |
| 栅极上拉 | 1k → +12V |
| 栅极串阻 / 下拉 | 100Ω / 100k |
| 预计管耗 | 约 0.3 W（0.4A 风扇），可不用散热片 |

### 抗噪

| 参数 | 数值 |
|---|---|
| 反馈低通 | 470Ω + 10µF → **约 35 Hz**（23kHz 衰减约 56dB） |
| 接地 | 功率地 / 信号地**单点汇合**于电源端子 |
| 反馈增益损耗 | 约 4.5%（470Ω 与 10k 分压造成，标定时补偿） |

### 传感器接口要求（供机械/采购参考）

| 项 | 要求 |
|---|---|
| 类型 | **单圈旋转电位器**（阻值 1 kΩ 左右） |
| 电气转角 | 约 300°（帆板只用 60°，取中间段） |
| 输出范围 | 0 ~ 约 1 V（**仅为满量程的 1/5**，见下方备注） |
| 源阻抗 | 越小越好（建议 ≤1 kΩ，否则与减法器 10k 输入产生负载误差） |
| 机械连接 | 柔性联轴器，**电位器不承受径向力** |

> **备注**：单圈电位器电气转角约 300°，帆板只用 60°，故输出仅约 1V。
> 若精度或抗噪不够，可加一级 5 倍放大回到 0~5V 满量程（需增加 1 个运放单元）。
