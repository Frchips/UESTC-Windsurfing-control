## 题目要点速查

| 项 | 内容 |
|---|---|
| 硬性 | 纯模拟（禁单片机）、洞洞板、整体结构、0.2m 自由落体后不许调试 |
| 基本要求（70分） | d=15cm，θ 可在 **10~60°** 变化；θ 稳定在 **45°±5°** |
| 发挥部分（30分） | d 在 **10~25cm** 任意，仍稳定 45°±5°，且 **5 秒**内回稳；其它（焊接/机械） |
| 供电 | 可外置，调速装置不必含电源 |
| 风扇 | 台式机散热风扇/直流轴流；**禁带自动调速功能** |

## 关键设计决策（已定）

| 项 | 结论 | 理由 |
|---|---|---|
| 供电 | **±12V 双电源**（自己带台式电源） | 12V 来自风扇；双电源来自"误差 e 是双极性的" |
| 运放 | **TL071×6 或 TL074×2**（JFET 输入） | 积分级偏置电流决定精度：LM324 的 45nA 会让 1µF 以 45mV/s 漂移 |
| PID 拓扑 | **并行型**（P/I/D 三支路 + 求和） | 微分支路 R_D2 定带宽、R_D1 定增益，**增益与带宽解耦** |
| 减法器 | **独立一级** | 产生可测量的 `e`，支持分步验收；设定值可调必须独立 |
| 角度传感 | 轴端磁铁 + 线性霍尔（零力矩）；电位器可作备用 | 电位器摩擦力矩会造成 ±3° 死区 |
| 帆板 | **10~25 g**，10cm×15cm | 45° 所需风速 v≈30√m，太重吹不上去 |
| 风扇 | 120mm、2 线、12V、0.3~0.5A、静压≥2mmH₂O | 4 线风扇违规风险；裸吹风量不够，需配 2:1 收敛导流口 |
| 功率级 | **待定**：线性（射极跟随 + TIP122）或 PWM（低边 MOSFET + LM393） | 线性无开关噪声；PWM 效率高但要处理干扰 |
