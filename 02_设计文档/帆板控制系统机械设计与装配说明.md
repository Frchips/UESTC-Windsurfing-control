# 帆板控制系统机械设计与装配说明

本文整理现有讨论，作为机械打样、采购和装配的参考。保留原方案中的亚克力底板、风扇移动导轨和螺杆立柱，补充轴承支撑、底板连接、帆板夹条及角度反馈结构。

> 尺寸说明：100 mm × 150 mm 的帆板尺寸以及角度、距离、时间和跌落要求来自题目；本文其余尺寸均为建议打样值，不是已完成校核的施工图。轴承座型号、安装孔方向、孔距、底板厚度和加工条件尚未确定，采购和打孔前须按实物或尺寸图复核。

## 1. 题目要求与机械设计边界

依据《控制方向-帆板控制系统设计与制作.pdf》：

| 项目 | 要求或含义 |
| --- | --- |
| 控制方式 | 采用纯模拟电路，不得使用单片机；电路在洞洞板上焊接 |
| 整体结构 | 风扇、帆板支撑及电路等安装成一个整体 |
| 可靠性测试 | 测评前进行 0.2 m 自由落体；不能额外包裹，之后不能调试或修复 |
| 帆板本体 | 宽 100 mm、高 150 mm，材料和厚度自定 |
| 基本调角 | d = 150 mm 时，能在 10°～60°范围内调节 |
| 基本稳角 | d = 150 mm 时，稳定在 45° ± 5° |
| 发挥要求 | d 在 100～250 mm 内变化后，5 秒内稳定在 45° ± 5° |
| 角度观察 | 转轴处必须安装量角器 |
| 转角 θ | 相对竖直向下方向的夹角，竖直向下为 0° |
| 间距 d | 风扇出风面到转轴竖直投影的距离，不是到倾斜帆板最近处的距离 |

帆板与光轴应固定在一起，光轴相对支架自由转动。工作角度由风力与控制回路维持，不通过螺丝把帆板锁在 45°。

## 2. 推荐的整机结构

### 2.1 固定部分与转动部分

| 部分 | 包含的零件 |
| --- | --- |
| 固定部分 | 底板、导轨基座、立柱、安装板、轴承座外壳、量角器、电位器外壳 |
| 转动部分 | 光轴、抱轴夹、帆板夹条、帆板、角度指针，以及被联轴器带动的反馈电位器转轴 |
| 可调整后锁紧的部分 | 风扇滑座、支架高度调节位置、电位器安装位置 |

整体连接关系：

~~~text
亚克力底板
├─ 导轨 → 可锁紧滑座 → 风扇及其支架
├─ 左侧立柱组 → 左安装板 → 左轴承座 ┐
├─ 右侧立柱组 → 右安装板 → 右轴承座 ┴─ 同一根水平光轴
│                                              ├─ 抱轴夹 → 夹条 → 帆板
│                                              ├─ 指针；量角器另固定于支架
│                                              └─ 联轴器 → 反馈电位器转轴
└─ 电路板支柱、接线端和线缆固定件
~~~

两个轴承座在帆板左右两侧，支撑同一根光轴。风扇向帆板正面吹风，光轴轴线横跨帆板宽度。两侧支撑不要伸进帆板摆动区域。

### 2.2 建议的起始布局

| 部位 | 建议打样值或要求 |
| --- | --- |
| 底板外形 | 长约 550～600 mm、宽约 250 mm |
| 亚克力厚度 | 可将 6～8 mm 作为试样起点，仍需验证局部连接与跌落表现 |
| 光轴高度 | 距底板上表面约 220 mm |
| 两侧支撑内侧净距 | 约 140～170 mm；再按夹具、轴承和限位件调整 |
| 光轴直径 | 初步考虑 4～6 mm；若可购轴承座不匹配，先统一轴、轴承、夹具和联轴器规格 |
| 导轨有效行程 | 至少 150 mm，并设置滑座锁紧与行程限位 |
| 风扇高度 | 对准帆板约 45°位置时的中部，建议预留高度调节槽 |
| 电路位置 | 固定在底板上，避开帆板摆动区和风扇滑座行程 |

导轨总长度不等于有效行程；还要扣除滑座长度和端部余量。光轴长度也应包含轴承宽度、两端限位件、指针及联轴器占用的空间。

## 3. 两孔轴承座是否需要两根螺杆

### 3.1 先区分“安装螺栓”和“支撑立柱”

两孔轴承座上的两个孔，通常用来把座体固定在安装面上，一般各配一颗安装螺栓。它们不等于必须由两根竖直长螺杆直接穿过。

推荐连接顺序：

**轴承座 → 两颗短安装螺栓 → 安装板 → 螺杆立柱 → 底板。**

本方案建议左右各两根螺杆，共四根立柱。这个数量来自对安装板支撑和支架刚度的考虑，并非由轴承座孔数直接决定。

### 3.2 判断轴承座类型

下表描述常见结构，最终以所购产品尺寸图为准。[S1]

| 类型 | 光轴与安装面的常见关系 | 水平光轴的常见安装方法 |
| --- | --- | --- |
| 底脚式、座式轴承座 | 轴线平行于安装面 | 放在水平顶板上，用两个底脚孔固定 |
| 两孔法兰式轴承座 | 轴线垂直于法兰安装面 | 固定在竖直安装板上，光轴横向穿过 |

判断时看轴线和安装面的关系，不只看两个孔在图片里位于“左右”还是“上下”。法兰座在竖直平面内旋转摆放后，两孔连线方向也会改变。

部分商品叫“光轴支座”“轴固定座”，用途是夹住不动的轴，未必带轴承。本方案需要光轴能相对支架灵活转动，因此采购时必须确认内部确实有适用的轴承，而非仅有一个夹紧孔。

### 3.3 保留螺杆的推荐装法

每一侧使用两根立柱，上面托住一块顶板；底脚式轴承座直接装在顶板上。若使用法兰式座体，再由顶板承托竖直安装板，并加角码或加强筋。

~~~text
底脚式：                           法兰式：

       轴承座／光轴                  法兰座装在竖直板上，光轴穿板
      ┌────────┐                             │
      └─┬────┬─┘                       竖直板│
   ═════╧════╧═════ 水平顶板              ┌───┘
       │      │                      ═══╧════════ 水平顶板
       │      │ 螺杆                      │      │ 螺杆
       │      │                          │      │
   ─────────────── 底板              ─────────────── 底板
~~~

安装板可以采用金属板、合适的金属角件或经验证的打印件；不要只靠一块很薄的悬臂片托住整个轴承。两根立柱之间增加横向连接，必要时设置斜撑。

如果所购底脚式座体的孔方向、孔径和立柱间距恰好匹配，直接穿长螺杆在几何上可能成立，但不建议把座体悬空、仅靠孔边几个螺母托住作为首版结构。SKF 的安装说明要求清洁、平整的支撑面；本文因此采用完整安装板承托座体。[S2]

M6/M8 立柱不必等同于轴承座安装螺栓规格。安装板可以一组孔接立柱，另一组孔接轴承座，避免因孔径不一致而勉强装配。

## 4. 螺杆如何连接亚克力底板

### 4.1 推荐做法：贯穿孔、上下夹持、金属加强板分担载荷

螺杆穿过底板，在底板上下分别设置金属加强板、垫圈和螺母。建议同一侧的两根螺杆共用一组上、下加强板，便于形成完整支脚。

下面表示一根立柱的局部剖面，螺杆竖直贯穿全部零件：

~~~text
               螺杆向上连接顶板
                      │
                   上螺母
                   大平垫圈
            ┌─────────────────┐
            │   上金属加强板   │
            ├─────────────────┤
            │   亚克力底板     │ ← 贯穿孔留配合余量
            ├─────────────────┤
            │   下金属加强板   │
            └─────────────────┘
                   大平垫圈
                   下螺母
                      │
        固定脚使下螺母最低点高于桌面，整机不支在螺母上
~~~

此处的“大平垫圈”和加强板要能覆盖最终通孔，并让螺母压力经较大的接触面传递；不能只根据螺纹规格选择过小的外径。

建议使用锁紧螺母或适当的机械防松结构。螺纹胶若使用，应限定在金属螺纹处并核对与亚克力的相容性，不能让不明配方流到板材上。

### 4.2 为什么不建议直接在亚克力上攻丝固定长立柱

本方案不把亚克力中的短螺纹作为高立柱的主要锚固。优先采用贯穿连接，配合金属加强板和支撑件；连接有松动时，先检查支架、孔隙和防松，而不是继续用力拧紧来压住晃动。

立柱高度约 220 mm 时，建议同时安排横向连接和斜撑，减小底部连接承受的撬动。是否能通过 20 cm 跌落，必须由完整样机验证。

### 4.3 底板孔径、边距和钻孔注意事项

亚克力的紧固孔不应不加区分地套用金属板的紧配合孔。ACRYLITE 针对板材点式紧固给出了留膨胀间隙、足够孔边距和采用护圈的建议；其示例要求孔径至少为螺栓直径的两倍，孔中心距板边至少为所钻孔径的 1.5 倍。[S3]

本项目应结合底板供应商说明、护套和实际连接形式确定孔径，不把上述留间隙建议误解成让螺杆在大孔中任意晃动。较大的孔可配合适配的护套或孔套，安装板与支撑结构承担定位和刚度。

采购与开孔顺序建议：

1. 确定底板厚度、立柱规格、上/下加强板和护套。
2. 根据护套外径及供应商要求确定亚克力开孔尺寸。
3. 按实际孔径复核边距和加强板覆盖范围。
4. 先在同材质边角料上试钻，确认工艺后再加工底板。

钻孔时应有背板支撑、可靠夹持并按板材厂商说明选择钻头及加工方法。[S4] 本文不给出“所有 M6 立柱都钻同一种孔”的通用值。

### 4.4 有条件时加入限压套管

可以在贯穿位置设置短限压套管，使上下金属加强板拧紧后的主要夹紧载荷经套管传递，亚克力仅被适度夹持。套管长度需要根据实际板厚及垫层压缩量配合，不应凭名义板厚随意制作。

这属于结构优化选项。没有合适的套管时，仍应保留加强板、控制夹紧程度，并通过试样验证；不要用拧紧力补偿不合理的结构间隙。

### 4.5 顶部安装板如何固定在螺杆上

顶部同样用“下螺母及垫圈 → 顶板 → 上垫圈及螺母”夹持。用下螺母调整高度，使左右两侧光轴中心等高，再锁紧上方螺母。

若采用底脚式轴承座，设目标光轴高度为 H、轴承中心距座体底面为 h，则顶板上表面高度约为 H − h。订购或切割螺杆时，还要计入底板、加强板、顶板、螺母堆叠和底部空间，不能直接把目标轴高当作螺杆长度。

## 5. 光轴、轴承与轴向限位

- 使用表面合适、直径匹配的光轴作转轴；螺杆只用于固定支撑。
- 先将同一根光轴穿过两个轴承，再调整两座位置，避免两边分别锁死后强行穿轴。
- 逐步锁紧安装螺栓，每一步检查转动是否变涩。
- 两端使用合适的轴环或原轴承组件规定的限位方式，避免明显左右窜动，也避免把轴承轴向顶紧。
- 带内圈紧定螺钉或偏心锁紧结构的轴承，应按对应型号说明装配，不能把所有轴承都当作同一种结构。
- 光轴外侧预留量角器指针、联轴器及传感器空间。

轴承和传感器的低阻力是本项目的关键选型条件。不能因为某个座体看起来结实就直接放大轴径、座体和夹具，导致整套转动部分过重或起动阻力过大。

## 6. 夹条：如何固定帆板

### 6.1 夹板区采用“三明治”结构

~~~text
螺钉头 → 前压条 → 帆板上缘 → 后夹条 → 垫圈和锁紧螺母
~~~

前后夹条横跨帆板宽度，两颗螺丝穿过夹条和帆板。紧固后既要防止板被抽出，也要避免压出波浪或裂纹。

| 项目 | 建议打样值 |
| --- | --- |
| 前压条 | 长 100 mm、高 12 mm、厚约 2 mm |
| 后夹条的夹板区域 | 长 100 mm、高 12 mm、厚约 3 mm |
| 夹持帆板上缘的高度 | 约 10～12 mm |
| 紧固件 | 两颗 M2.5，配垫圈和锁紧螺母 |
| 两孔横向位置 | 距帆板左右边各约 15 mm |
| 两孔竖向位置 | 距帆板上边约 6 mm |
| 夹板区通孔 | 可先考虑 2.8～3 mm，再按实际加工调整 |

以上小孔建议用于此处薄帆板及夹条的打样，不可直接套用到亚克力底板的立柱紧固孔。帆板本体仍保持 100 × 150 mm，夹条覆盖其上缘的一部分。

前后夹条先对孔，再定位薄帆板孔。两颗螺丝交替、逐渐拧紧，检查夹条是否平直。

### 6.2 抱轴区与夹板区分别锁紧

后夹条连接两个靠近左右两端的抱轴夹，抱轴位置可先以距两端各约 20 mm 作为布局起点，正式画图时避开夹板螺丝和轴承。

| 连接 | 紧固后应达到的状态 |
| --- | --- |
| 抱轴夹与光轴 | 手固定光轴并轻扳帆板时，连接件不相对光轴转动 |
| 前后夹条与帆板 | 帆板不滑移、不抽出，孔边无裂纹，板面不被压弯 |

普通两片平条直接同时夹一根较粗圆轴和一片薄板，往往难以分别控制两处夹紧。本文建议采用独立的抱轴紧固件与夹板紧固件。

### 6.3 有 3D 打印条件时的零件拆分

推荐打印：

1. 一个主件：后夹条，以及左右两个下半抱轴座。
2. 两个小上盖：与下半抱轴座合成抱轴孔，各自有紧固件。
3. 一根前压条：用于夹板区。

主件在下方设置平直夹板区域，上方另设抱轴结构，因此其整体高度并不只有表格中夹板区的 12 mm。

轴线尽量靠近帆板上缘并接近板厚中间平面。可先以轴线高于帆板上缘约 3～5 mm 为布局目标，再按抱轴夹壁厚、螺丝空间和打印工艺调整。抱轴孔按实际打印公差试配。

### 6.4 没有打印条件时

可用铝条制作夹板区，再通过带适用安装面或安装孔的成品夹紧轴环连接光轴。先核对成品轴夹的尺寸、重量、安装面朝向和孔位，再加工夹条。

此处的抱轴夹要随光轴转动；安装在支架上的轴承座外壳保持不动，两者不要混淆。不要把帆板整体装到离轴线很远的一侧，以免增大重心偏置。

## 7. 帆板材料与摆动空间

可先试 0.5～1 mm PET 薄板，以风力余量、板面刚度和实际抖动情况决定最终厚度。必要时增加轻质边框或局部加强，但每次改动后都要重新验证风扇能力。

支架、风扇滑座、电路板和线缆均应避开帆板的整个摆动包络。设置独立机械限位，放在正常工作区间之外，不使用电位器内部挡块承受碰撞。限位位置按实际余量确定，可先检查约 70°～80°附近的可行性，并保留竖直附近所需活动范围。

## 8. 量角器与人工读数

量角器固定在一侧支架上，指针固定在光轴端部。两者中心与转轴中心重合，量角器平面与帆板摆动平面平行。

安装与校准顺序：

1. 用铅垂线确定竖直向下方向，并标为 θ = 0°。
2. 检查帆板断风时是否能自由回落至竖直附近。若明显偏斜，先检查摩擦、连接干涉和重心偏置。
3. 固定指针，使读数对应板面相对竖直的角度。
4. 指针靠近刻度但不接触量角器；观察时尽量正视，减小视差。

不要仅把“帆板卡住后停在哪里”重新标成零位，以免掩盖机械问题。常见量角器自带零刻度方向也未必正好朝下，可另作清晰标记。

## 9. 反馈电位器与纯模拟控制

### 9.1 设定与反馈是两个不同元件

| 元件 | 安装位置 | 作用 |
| --- | --- | --- |
| 角度设定电位器 | 面板或电路板 | 人工给出目标角度 |
| 角度反馈电位器 | 光轴一端，外壳另有固定支架 | 随帆板转动，输出实际角度对应电压 |

本方案采用电阻式反馈电位器，以直接提供模拟信号；不引入单片机读取的数字角度编码器。反馈件的阻值可以先以 10 kΩ 作为候选，但必须确认线性特性、有效电气转角和足够小的转动阻力。

### 9.2 机械安装

电位器外壳独立固定，转轴通过匹配轴径的小联轴器连接光轴。两侧轴承承担帆板重量，电位器不作为承重轴承。联轴器应无明显空回，并避免轴线偏差给电位器造成侧向负载。

装配时给电位器两端行程留余量，不将其自身机械端点作为帆板零位或限位。反馈线固定在外壳一侧，避免线缆牵扯帆板。

### 9.3 反馈标定与电路接口

用稳定参考电压给电位器供电，滑动端信号经合适的缓冲及信号调理后作为角度反馈。输入范围应与所用运放的供电和允许输入范围匹配。

分别在量角器 0°、30°、60°位置记录反馈电压，检查是否平滑、单调且重复。确认角度增大时，反馈方向与误差电路定义一致。

控制链路建议为：

**目标角度电压 − 实际角度反馈电压 → 误差电路 → 模拟控制器 → 风扇功率驱动 → 风扇 → 帆板。**

误差的实际接线极性还需结合驱动级验证：在正常反馈方向下，目标角度高于实际角度时，系统应提高风力，而不是继续降低风力。

## 10. PID 参考电路如何使用

《由一片4运放构成的PID电路.pdf》可以参考其 P、I、D 分支与输出求和方式，但它不是完整的帆板控制系统。还需补充角度传感、目标设定、误差形成及风扇功率驱动。

原文的积分时间常数为 22～462 秒，微分部分也有对应的时间常数调整范围。这些数值不能直接视作本帆板系统的合适参数，更不能将积分时间常数直接等同于整机稳定时间。

题目要求距离变化后 5 秒内稳定，因此应结合实际帆板、风扇和摩擦重新选择、调整参数。建议先完成机械调试与负反馈方向检查，验证风力余量，再由较简单的控制配置逐步调试，避免机械卡滞与参数问题混在一起。

## 12. 装配顺序与验证

### 12.1 建议装配顺序

1. 确定轴承座类型和尺寸，统一光轴、轴承、抱轴夹、联轴器规格。
2. 在底板上排布导轨、两侧立柱组、电路板和帆板摆动包络，确认互不干涉。
3. 完成亚克力连接试样，确定加强板、孔套及孔位后加工正式底板。
4. 安装立柱、上下加强板、顶板及支撑件，初步调平。
5. 用同一根光轴找正两个轴承座，逐步锁紧并反复检查转动阻力。
6. 安装抱轴连接件、帆板和夹条，检查不打滑、不抽出。
7. 安装量角器与指针，检查竖直零位。
8. 先不接反馈电位器，检查帆板自由摆动。
9. 接入反馈电位器后再次比较阻力，完成电压标定。
10. 安装风扇及距离标尺，完成开环风力验证，再接入控制回路调试。
11. 完成固定脚、防松、限位和线缆整理，最后用完整样机验证跌落后的状态。

### 12.2 关键检查项目

| 检查 | 方法与判据 |
| --- | --- |
| 低阻力摆动 | 从约 10°处轻放，应能顺畅回落；不得因干涉、偏心或夹紧而长期停在明显偏角 |
| 接反馈后的阻力 | 比较接电位器前后状态，明显变涩时先解决机械问题 |
| 帆板固定 | 手固定光轴后轻扳板面，各连接无相对滑移 |
| 角度反馈 | 0°、30°、60°的电压平滑、单调、可重复 |
| 距离标尺 | 用出风面到转轴投影核对 100、150、250 mm 三个位置 |
| 最远距离风力 | d = 250 mm 时最大风力能将帆板吹过 45°，并保留控制余量 |
| 基本调角上限 | d = 150 mm 时具备达到 60°的风力余量 |
| 反馈方向 | 目标高于实际角度时，回路应提高风力 |
| 全行程干涉 | 正常摆动范围内，帆板、指针、夹具及联轴器不碰支架和线缆 |
| 跌落后状态 | 不经修复或重调检查底板、支架、零位、连接及控制表现是否仍满足题目 |

以上自由摆动描述是机械调试目标，不是另行增加的题目评分条款。缺少最终风扇、帆板材料及完整样机数据时，不能承诺这些建议尺寸必然满足性能与跌落要求。

## 13. 开工前仍需确认的尺寸

- 轴承座实际型号、内径、安装孔径与孔距、中心高、安装面朝向。
- 光轴长度及两端附件的占用空间。
- 立柱规格、安装板厚度、上下螺母堆叠和底部离桌空间。
- 亚克力材质、实际厚度、供应商加工要求、护套与加强板尺寸。
- 风扇外形、安装孔距、供电与最远距离下的风力余量。
- 反馈电位器的有效电气行程、轴径、起动阻力及支架形式。

在这些数据确定之前，本文可用于选择结构与准备试样，不用于直接批量开孔。
